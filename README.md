# SDGs Gender Equality Game

An educational HTML map-based game designed to promote awareness of **SDG 5: Gender Equality** through interactive gameplay and quizzes.

## Overview

This project is a two-level educational game based on the **United Nations Sustainable Development Goals (SDGs)**, focusing on **Gender Equality**.

Players explore a village, enter huts, answer questions, and progress through challenges while learning important concepts about fairness, equal opportunities, and equal rights.

---

## Features

### Level 1 – Village Quiz Challenge
- Interactive village map
- Clickable straw huts
- 10 multiple-choice questions about gender equality
- Score counter displayed in real time
- Questions can only be answered once
- End-game evaluation system:
  - Score below 8 → Retry challenge
  - Score 8 or above → Unlock next level

### Planned Level 2
Future gameplay ideas include:

- Community Equality Missions
- Decision-based adventure scenarios
- Time attack challenges
- Equality city-building simulation
- Final boss challenge
